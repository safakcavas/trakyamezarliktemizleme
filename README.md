# Trakya Mezar Bakım ve Temizlik Hizmetleri

Bu web sitesi **trakyamezarliktemizleme.site** alan adı için geliştirilmiş, Next.js 16 (App Router), React 19 ve Tailwind CSS v4 ile inşa edilmiş kurumsal ve yüksek dönüşüm odaklı web uygulamasıdır.

## 🌐 Özellikler

- **Trakya Kapsamı:** Tekirdağ (Çorlu, Süleymanpaşa, Çerkezköy, Malkara vb.) ve Kırklareli (Lüleburgaz, Babaeski vb.) ilçe ve köyleri için detaylı köy arama ve liste desteği.
- **Edirne Yönlendirmesi:** Edirne ve köyleri arandığında veya seçildiğinde doğrudan `edirnemezarliktemizleme.site` adresine yönlendirme.
- **İnteraktif Fiyat Hesaplayıcı:** Tek tıkla il, ilçe ve hizmetleri seçerek tahmini bedel hesaplama ve doğrudan WhatsApp teklif mesajı oluşturma.
- **Şeffaf Hizmetler:** Mermer beyazlatma, yabani ot temizliği, canlı mevsimlik çiçeklendirme, mezar taşı yazı boyama, mermer derz tamiratı ve ağaç budama.
- **İletişim:** `0530 230 15 22` numarası ile tek dokunuşla arama ve WhatsApp sipariş hatları.
- **Mobil Uyumlu & SEO Optimize:** JSON-LD LocalBusiness şeması, Açık Grafik (OpenGraph) etiketleri, `robots.ts` ve `sitemap.ts`.

## 🚀 Çalıştırma

```bash
# Bağımlılıkları yükleme
npm install

# Geliştirme sunucusu
npm run dev

# Üretim için derleme
npm run build
```
